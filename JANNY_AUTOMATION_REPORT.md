# Janny Automation Result

Проверка: 2026-10-23. Автоматическое скачивание встроено в этап JannyAI после DataCat и подтверждено живым прогоном в Docker без сохранённых cookies и ручного участия.

## Behavior

Полная карточка DataCat отправляется сразу. Если DataCat возвращает ошибку или карточку без определения, worker запускает Camoufox + Xvfb и получает публичные поля JannyAI из JSON props Astro. X11 XTEST нажимает флажок текущего шаблона Cloudflare после ожидания готовности. Затем существующий PNG writer создаёт Character Card V2. UUID и содержимое персонажа не зашиты в рабочий код. При неудаче сохраняется следующий этап Janitor proxy.

Bookmark относится к избранному и исключён из задачи скачивания. Существующий экспорт lorebooks сохранён; книги переносятся, только если источник передал их содержимое.

## Isolation And Dependencies

Camoufox 0.5.8 использует отдельное окружение с Playwright 1.62.0; основное окружение сохраняет Playwright 1.63.0. requirements-janny.lock закрепляет зависимости и wheel-хеши. Бинарный Firefox 156.0.1-beta.36 для Linux x86_64 закреплён SHA256; модель fingerprint проверяет официальный установщик Camoufox. Оба ресурса устанавливаются при сборке Docker. Первый интеграционный прогон выявил отсутствие модели в образе; её установка перенесена в build, исправленный образ проверен без сети и с read-only root.

Браузер получает только временный HOME/кэш, системные параметры SSL/языка и PATH. BOT_TOKEN, DATABASE_URL, cookies и пароли аккаунтов не передаются. Контейнер работает непривилегированным пользователем с read-only root, cap-drop ALL, no-new-privileges, seccomp и конечными лимитами памяти, процессов и времени.

Сетевой CONNECT-туннель сохраняет native TLS, ограничивает точные домены и порт 443, проверяет публичность DNS и подключается к проверенному IP. Есть лимиты соединений, трафика и времени; WebSockets и service workers запрещены. Аватар загружается существующим safe_http. Ошибки передаются через allowlisted diagnostics без тел ответов, заголовков и произвольных сообщений.

## Limits And Deployment

Прохождение проверки подтверждено для текущих Cloudflare, шаблона страницы и сети. Бессрочную совместимость со сторонним сайтом гарантировать нельзя. Адаптер использует координаты проверенного шаблона Cloudflare и формат сериализации Astro; их изменение может потребовать исправления. Платные solver/API не используются, квот стороннего браузерного сервиса нет.

Локальный проверочный образ: janitor-bot:janny-fallback-check. Запущенный janitor_test_bot остаётся на прежнем образе; сервер и рабочий бот не обновлялись.
