# Server Cleanup

## Cause

Лог завершился ошибкой `no space left on device` при распаковке слоя Camoufox в `/var/lib/containerd/.../opt/camoufox/libxul.so`. Сам образ занимает около 3,9 GB; при сборке дополнительно используются архив браузера, кэш сборок и временные слои. `.copyignore` управляет копированием исходников, Docker build context фильтруется отдельно через `.dockerignore`.

## Files To Remove

Из корня проекта можно удалить `.cache/`, `__pycache__/`, `.npm-cache/`, `.pytest_cache/`, `.mypy_cache/`, `.ruff_cache/`, `.venv/`, `venv/`, `node_modules/` и `graphify-out/`, если они были скопированы на сервер. Это локальные зависимости, диагностические браузеры, тестовые PNG, снимки, логи и сгенерированная карта. В локальной `.cache/` также удалён `janitor_auth_state.json`: резервному Janitor-пути может потребоваться повторный вход; автоматический Janny-путь использует новый профиль.

Локально граф сохранён для навигации по исходникам и исключён из копирования на сервер. Список фактически удалённых локальных файлов и объёмы находятся в `CLEANUP_REPORT.md`.

`.env` включён в копирование согласно запросу пользователя. Перед обновлением убедитесь, что копируемый `.env` предназначен для рабочего бота. Файл не читается и не изменяется этой очисткой; `.env.*` исключены.

Из копирования также исключены `.git/`, настройки редакторов и агентов, `tests/`, Markdown-документация, локальный Dockerfile проверок, утилиты локального входа и генерации lock-файлов. Эти небольшие файлы можно оставить на сервере: удаление кэшей и Docker build cache даёт основное освобождение места.

## Commands

Сначала перейдите в реальную папку этого проекта на сервере и проверьте путь. Следующий блок откажется работать из папки с другим именем. Он удаляет только перечисленные каталоги внутри корня исходников.

```bash
pwd
test "$(basename -- "$PWD")" = get_janitor_characters_bot || exit 1
test -f Dockerfile && test -f docker-compose.yml && test -f .env || exit 1
for name in .cache __pycache__ .npm-cache .pytest_cache .mypy_cache .ruff_cache .venv venv node_modules graphify-out; do
    rm -rf -- "./$name"
done
docker system df
df -h
df -i
docker buildx prune --all --force
docker system df
df -h
```

`docker buildx prune --all --force` очищает неиспользуемый кэш выбранного builder для всех проектов. Образы контейнеров, сами контейнеры и volumes сохраняются; последующие сборки могут занять больше времени. Команды Docker могут потребовать `sudo`, если текущий пользователь не имеет доступа к daemon. При собственном Docker context/builder выполняйте очистку в том, где происходила неудачная сборка.

Тестовые образы этого проекта можно удалить отдельно, если они есть на сервере и не используются контейнерами:

```bash
docker image rm janitor-bot:camoufox-probe janitor-bot:native-probe janitor-bot:lorebook-check janitor-bot:slug-check janitor-bot:db-check janitor-bot:security
```

Отсутствующий или используемый образ Docker не удалит этой командой. Сохраните рабочий образ и образ для отката. Имена `janitor-bot:*` относятся к локальному стенду и могут отсутствовать на сервере; не заменяйте список глобальной очисткой образов.

После освобождения места повторите сборку:

```bash
docker compose up -d --build
```

## Persistent Data

Очистка не затрагивает базы, Docker volumes и примонтированный каталог `/srv/projects/data/get_janitor_characters_bot/cache`. Этот каталог отличается от `.cache/` внутри исходников. Не удаляйте его как часть очистки исходников. Не удаляйте вручную `/var/lib/docker` или `/var/lib/containerd`; используйте команды Docker.

Если после очистки места всё ещё недостаточно, нужен дополнительный запас диска для сборки/распаковки. Исключение служебных файлов из копирования не уменьшает необходимые бинарные файлы браузера внутри образа.
